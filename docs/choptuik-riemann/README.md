The **Choptuik–Riemann monograph** (Russian, ~4.5 MB Word document) — a research study connecting **Choptuik critical-collapse scaling** with the spectral story of the Riemann zeros told by the rest of the repository. Choptuik scaling describes the universal, scale-invariant behaviour seen at the threshold of gravitational collapse; this monograph examines that universality through the same statistical lens the repository applies elsewhere (scaling laws, universality classes, and the spectral statistics that link deterministic systems to random-matrix behaviour).

The document is the only artifact of this sub-program and lives solely in this folder — there is no PDF or LaTeX edition. It is covered by the repository licence like all other documentation. Readers coming from the AB-Cloud side will recognise the methodological spine: empirical scaling fits with bootstrap confidence bands, treated as evidence only when they survive surrogate testing.
