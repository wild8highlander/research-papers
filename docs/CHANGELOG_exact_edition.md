## 4. Точные тождества (новый раздел)

В 2D для div-free $u$ поворот $u'=\cos\theta_b\,u+b\,(\hat z\times u)$:
$\omega'=\cos\theta_b\,\omega$ — точно ($7{,}1\cdot10^{-14}$);
$|u'|^2=|u|^2$ — точно ($0$); $\operatorname{div}u'=-b\,\omega$ (уходит в давление).
