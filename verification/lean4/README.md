# Lean 4 — Формальная верификация

Машинно-проверяемые формальные доказательства математических утверждений
из шести исследовательских разделов с использованием Lean 4 и Mathlib4.

## Что внутри

Формальные доказательства для всех 6 исследовательских разделов:
- Раздел 1: Поправка b и регулярность 3D Navier-Stokes
- Раздел 2: Аналитическое доказательство регулярности NSE
- Раздел 3: Мононим AB-Cloud (гамильтониан Хофштадтера)
- Раздел 4: Уравнение KdV и b-поправка
- Раздел 5: Аттрактор Клейна и мост к Navier-Stokes
- Раздел 6: Нули Римана и гипотеза Гильберта-Пойа

## Структура

```
lean4/
├── lean-toolchain                 конфигурация Lean
├── lakefile.lean                  манифест проекта
├── Main.lean                      точка входа для проверки типов
├── Test.lean                      численный мост
├── README.md                      этот файл
├── TODO_sorry.md                  список незавершённых доказательств
└── ResearchPapersVerification/
    ├── Basic.lean                 агрегатор модулей
    ├── Common/Foundation.lean     общие определения
    ├── Section1_CorrectionB/      раздел 1
    ├── Section2_PreprintNSE/      раздел 2
    ├── Section3_ABCloud/          раздел 3
    ├── Section4_KdV/              раздел 4
    ├── Section5_KleinAttractor/   раздел 5
    └── Section6_RiemannZeros/     раздел 6
```

## Стратегия Mathlib

Используется гибридный подход:
- Mathlib предоставляет стандартные математические структуры
- Кастомные определения реализуют исследовательские объекты

## Сборка

```
cd lean4
lake build
lake exe check
lake exe test
```
