# Isabelle/HOL — Формальная верификация

Формальные доказательства для всех 6 исследовательских разделов.

## Что внутри

- `Section1_CorrectionB/CorrectionB.thy` — поправка b
- `Section2_PreprintNSE/ProofChain.thy` — цепочка доказательства NSE
- `Section3_ABCloud/Hofstadter.thy` — гамильтониан Хофштадтера
- `Section4_KdV/KdV.thy` — уравнение KdV
- `Section5_KleinAttractor/Klein.thy` — квартика Клейна
- `Section6_RiemannZeros/RiemannZeros.thy` — нули Римана

## Сборка

```
cd isabelle
isabelle build -D .
```
