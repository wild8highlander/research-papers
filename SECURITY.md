# Security Policy

## Supported Versions
| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability
Please report security vulnerabilities privately via GitHub Security Advisories at [https://github.com/wild8highlander/research-papers/security/advisories/new](https://github.com/wild8highlander/research-papers/security/advisories/new).

Do **not** report security vulnerabilities through public GitHub issues.
