The **JavaScript asset of the AB-Cloud documentation site**: `mathjax.js` bootstraps MathJax rendering for the MkDocs Material pages of the snapshot, so formulas in the AB-Cloud docs (quickstart, monographs, verification pages) typeset correctly. It is referenced from the snapshot's `mkdocs.yml` `extra_javascript` block and is intentionally the only script here — the docs stay dependency-light.
