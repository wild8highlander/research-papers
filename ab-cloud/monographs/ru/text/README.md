The **Russian text of the v22 monograph in five parallel formats** plus a presentation deck and the v221 revision — one research result, every consumable form. The canonical chain: `AB_Cloud_Monograph_v22_RU.md` (Markdown, readable on GitHub) → `.tex` (LaTeX source) → `.docx` (Word manuscript) → `.html` (self-contained page) → `.pdf` (print-ready), with `AB_Cloud_Monograph_v22_RU_presentation.pptx` as the talk deck and the `_v221` files as the later editorial revision. The `preprint/` subfolder holds the standalone preprint edition (PDF + LaTeX) derived from this text. All formats carry the same content and the same figure references into [`../figures/`](../figures/README.md).
