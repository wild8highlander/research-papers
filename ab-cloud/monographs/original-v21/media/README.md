The **media library of the original v21 monographs** — 74 PNG images (~17.8 MB) referenced by the v21 html/docx editions: every figure, plot and diagram of the original editions under their original names (`image1.png` … `image16.png` plus the content-hashed names used by the docx pipeline). The v21 Markdown sources link into this folder; keeping it intact is what makes the historical editions render correctly offline.
