The **original v21 monograph, English edition** — the author's manuscript as it accompanied the v21 code state, preserved unchanged for provenance. Two subfolders: `text/` (the manuscript in md/docx/html/pdf, including the *with_Verification* and *corrected* variants) and `presentation/` (the talk deck). This is the edition whose claim «idx = 38 is unique» was later **refuted** by the 10-language re-verification — which is precisely why the original is preserved unmodified, with the correction documented in the v22 editions and the verification suite.
