The **frozen input data** of the 3D lattice laboratory: `zeros1.txt` (~1.8 MB) — the table of embedded Riemann ζ-zeros the simulations read deterministically. Every run of the lab (see `outputs/`) consumes this exact file; nothing is downloaded at runtime, which is what makes the results reproducible bit-for-bit. The companion dataset used by the 10-language verification suite lives in [`verification/data/`](../../verification/README.md); this one belongs to the 3D laboratory's own pipeline (its README documents the 5 000-zero embedding).
