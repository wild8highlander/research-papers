The dashboard's **shared UI components** — a single `ui.jsx` module exporting the building blocks (cards, tables, badges, navigation chrome) reused by all three pages. Keeping the kit in one file is a deliberate choice: the dashboard stays a small, auditable bundle rather than a component zoo.
