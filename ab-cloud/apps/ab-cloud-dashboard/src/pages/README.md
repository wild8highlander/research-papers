The dashboard's **three page components**. `RunReport.jsx` renders archived verification runs (the report format of `ab-cloud/results/`); `Spinor64.jsx` visualises the 64-structure spinor classification with its orbit structure 28/21/7/7/1; `ZerosStats.jsx` draws the spacing/⟨r⟩/KS statistics over the frozen ζ-zero datasets. Heavy computation is delegated to the sibling Web Worker; pages stay presentational.
