The **frozen datasets of the spinor64 block** — the reference verification of all 64 spinor structures. Four files, read by every spinor64 run and by the dashboard's Spinor64 page: `reference_spectrum.csv` (the reference spectrum the isospectrality check diffs against), `reference_stats.json` (the reference statistics with tolerances), `spinor_classes.csv` (the 64 structures with their PSL(2,7) orbit labels 28/21/7/7/1 and Arf invariants), and `klein_graph_edges.csv` (the Klein-quartic graph edge list the constructions build on). Freezing these files is what makes 64/64 GUE-consistency an auditable, bit-reproducible statement.
